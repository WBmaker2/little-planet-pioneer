# 《꼬마 행성 개척자》 교실 플레이테스트 진행안

## 목적

게임이 재미있는지, 목표와 선택지가 이해되는지, 3~15분 쉬는 시간에 부담 없이 끝낼 수 있는지 확인한다. 학업 성취나 지능을 측정하지 않는다.

## 준비

- 교사 1명과 학생 3~6명
- 학생 1명당 기기 1대 또는 2명당 기기 1대
- 테스트 미션: `첫 태양빛` 3분, `관측소의 신호` 10분
- 학생 이름·학번·얼굴·음성·계정 정보는 기록하지 않는다.
- 학교와 보호자의 참여 승인 및 학생의 자발적 참여 의사를 먼저 확인한다.

## 진행 순서

1. “정답을 맞히는 시험이 아니라 재미있는 탐험 게임”이라고 설명한다.
2. 조작법은 목표와 버튼 위치만 설명하고 전략은 알려주지 않는다.
3. 3분 미션을 1회 플레이한다.
4. 학생이 원하면 10분 미션을 1회 플레이한다.
5. 교사는 개입하지 않고 관찰한다. 30초 이상 멈추거나 직접 도움을 요청할 때만 “화면에서 무엇을 확인해 볼까요?”라고 질문한다.
6. 종료 후 재미·어려움·다시 하고 싶은지 각각 1~5점으로 묻는다.

## 관찰표

| 항목 | 기록 방법 |
|---|---|
| 첫 행동까지 시간 | 30초 미만 / 30~60초 / 60초 초과 |
| 목표 이해 | 학생이 자기 말로 설명 / 설명 필요 |
| 로봇 선택 | 능력을 읽고 선택 / 무작위 선택 / 선택하지 않음 |
| 미리보기 이해 | 문장을 읽고 위치 변경 / 읽었지만 유지 / 사용하지 않음 |
| 자원 판단 | 부족 원인을 설명 / 도움 필요 |
| 전략 변경 | 10분 미션에서 1회 이상 변경했는가 |
| 완료 여부 | 완료 / 부분 보상 / 중단 |
| 재미 점수 | 1~5 |
| 어려움 점수 | 1~5 |
| 재플레이 의향 | 예 / 모르겠음 / 아니오 |

## 중단 기준

학생이 불편해하거나 그만두고 싶다고 말하면 즉시 종료한다. 기기 오류, 눈의 피로, 네트워크·학교 운영 문제도 중단 사유로 본다. 게임 안 관찰 기록은 식별정보가 없는 요약만 사용하며, 교사가 별도로 학생을 특정할 수 있는 메모와 결합하지 않는다.

## 해석 기준

- 재미 평균 4점 이상이고 어려움 평균 4점 이하이면 현재 흐름을 유지한다.
- 목표 이해에서 설명 필요가 절반 이상이면 미션 카드와 첫 사건의 안내를 단순화한다.
- 미리보기 사용률이 낮으면 위치별 문장과 아이콘의 크기를 높인다.
- 3분 미션을 대부분 2분 이내에 끝내면 사건 또는 배치 선택을 하나 추가한다.
- 10분 미션에서 대부분 중단하면 목표 수나 사건 수를 줄이고, 학생의 자유 의견을 우선한다.
