# 꼬마 행성 개척자 MVP 검증 기록

검증일: 2026-08-11 (Asia/Seoul)

## 자동 검증

- `vitest run`: 8개 파일, 27개 테스트 통과
- `tsc --noEmit`: 오류 0건
- `vite build`: 프로덕션 빌드 성공
- `playwright test`: 브라우저 시나리오 8개 통과
- 콘텐츠 불변 조건: 3개 지역, 15개 미션, 12개 사건, 6개 건물, 4개 지원 로봇

## 플레이 흐름

- 첫 화면에서 두 번의 선택으로 3분 임무 진입
- 시설 선택, 5×5 타일 배치, 자원 차감, 사건 선택, 부분/완료 결과와 보상 표시
- 사건 선택 전에 비용·보상·회복도 변화 표시; 감당할 수 없는 선택은 비활성화
- 15분 임무를 시작하고 저장한 뒤, 페이지를 새로 열어도 `계속하기`로 복구
- 손상된 활성 임무는 버리고 유효한 프로필과 설정은 유지
- 브라우저 저장소가 차단되거나 가득 차도 현재 세션은 메모리에서 계속 실행

## 화면·입력·안전 점검

- 1024×768: HUD, 건설판, 사건 패널, 완료 버튼이 겹치지 않음
- 768×1024: 세로 스크롤로 모든 조작에 접근 가능하고 가로 넘침 없음
- 키보드 Tab/Enter로 첫 임무 진입 가능; 포커스 링과 44px 이상 조작 영역 적용
- `prefers-reduced-motion`에서 전환 애니메이션 최소화
- Playwright 요청 감시 결과 외부 네트워크 요청 0건
- 소스 검색 결과 광고, 채팅, 결제, 뽑기, 외부 순위표, 데이터 공유 기능 없음
- 익명 이름은 기기 안에만 저장되며 DOM 속성에 안전하게 할당

## 독립 코드 리뷰 반영

반영: 저장 데이터 검증·저장소 예외 복구, 사용자 입력의 안전한 렌더링, 사건 선택 정보 공개, 실제 새로고침 재개, 가로 넘침 검사, 빈 지도 안내, 키보드 포커스 강화.

## 알려진 비차단 제한사항

- 지원 로봇 4종은 콘텐츠 데이터로 포함되지만 능력 선택 UI와 실제 보정 효과는 후속 버전 범위다.
- 건물의 생태·인접 효과 계산은 도메인 엔진에 있으나, 생산 턴과 배치 보너스 미리보기는 후속 버전 범위다.
- 플레이 시간은 강제 타이머가 아니라 목표 복잡도와 사건 수를 나타내는 권장 시간이다.
- 세로 화면은 전체 건설판 가독성을 우선해 사건 패널과 완료 버튼까지 스크롤이 필요하다.
- Phaser가 포함된 단일 JavaScript 번들은 약 1.51MB(압축 약 350KB)다. 현재 로컬 MVP에는 지연 로딩을 적용하지 않았다.
- 실제 학생 집단의 평균 완료 시간·난이도·재미 평가는 교실 플레이테스트가 필요하다.

## 판정

승인된 구현 계획의 로컬 플레이 가능 MVP 기준을 충족한다. 공개 배포 전에는 실제 학생 플레이테스트와 지원 로봇/생산 턴의 2차 구현을 권장한다.
