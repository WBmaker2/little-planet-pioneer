# 전략 깊이 확장 검증 기록

검증일: 2026-08-11

## 자동 검증 결과

- Vitest: 9개 파일, 35개 테스트 통과
- TypeScript: `tsc --noEmit` 오류 0건
- Vite 프로덕션 빌드 성공
- Playwright: 10개 브라우저 시나리오 통과
- 콘텐츠: 15개 미션, 12개 사건, 6개 건물, 4개 지원 로봇 유지

## 구현 확인

- 물방울·반짝이·똑딱이·새싹이 중 하나를 미션 시작 전에 선택
- 로봇 선택이 체크포인트에 저장되고 새로고침 후 유지
- 시설 배치 성공 시 비용 차감과 생산 턴이 같은 불변 상태 전환으로 처리
- 태양광, 재활용기, 작업장, 온실, 관측소, 통신 기지 생산·회복 효과 적용
- 지역 효과와 인접 효과를 배치 턴에 반영
- 빈 타일 포인터·키보드 포커스 시 배치 미리보기 문장 표시
- 사건 비용·보상·회복도 변화 사전 표시

## 교실 관찰 도구

- 로컬 메모리 기반 `PlaytestObserver` 추가
- 기록 항목: 미션 시작, 로봇 선택, 미리보기, 첫 행동, 도움 요청, 완료/중단
- 교사용 설정 화면에서 관찰 요약과 초기화 가능
- 학생 이름·학번·계정·외부 전송 없음
- [교실 플레이테스트 진행안](../../playtests/little-planet-pioneer-classroom-protocol.md) 작성

## 화면 점검

- 1024×768: 로봇 선택·자원 HUD·건설판·사건 패널이 한 화면에서 읽힘
- 768×1024: 로봇과 건설 선택이 2열로 재배치되고 세로 스크롤로 이어짐
- 키보드 포커스, 모션 감소, 외부 네트워크 0건 검증은 기존 회귀 시나리오로 유지

## 실제 학생 검증 상태

실제 학생·교사 참여가 이 실행 환경에는 없으므로 재미·난이도 점수는 아직 수집하지 않았다. 학교 또는 보호자 승인 후 진행안을 사용해 3분 미션과 10분 미션을 관찰하고, 결과를 코드와 분리된 교사 메모로 해석해야 한다.

## 알려진 제한사항

- 생산 효과는 배치 즉시 1회 적용된다. 별도 턴 종료 버튼이나 날씨 변화 단계는 후속 확장이다.
- 지원 로봇은 현재 4종의 고정 능력을 제공하며 추가 해금·레벨 시스템은 없다.
- 관찰 요약은 현재 브라우저 세션 메모리에만 존재하며 파일 내보내기는 제공하지 않는다.
