# 《꼬마 행성 개척자》 게임 설계서

- 작성일: 2026-08-11
- 상태: 사용자 승인 설계
- 대상: 초등학교 5~6학년
- 플레이 방식: 1인 플레이
- 권장 세션: 3~15분
- 우선순위: 재미 > 자연스러운 사고 활동 연습 > 교육 설명

## 1. 제품 개요

《꼬마 행성 개척자》는 제한된 물·에너지·부품을 활용해 외계 행성을 탐험하고 기지를 건설하며 생태계를 회복하는 전략 게임이다. 전투, 확률형 보상, 채팅 없이도 탐험·수집·건설·선택의 결과를 통해 반복 플레이의 재미를 제공한다.

게임은 특정 교과 지식을 시험하지 않는다. 대신 자원 비교, 우선순위 판단, 결과 예측, 실패 원인 분석, 전략 변경을 반복하게 해 계획·기억·문제 해결과 관련된 사고 활동을 자연스럽게 경험하게 한다. 게임이 지능이나 학업 성취를 직접 향상한다고 주장하지 않는다.

### 성공 기준

1. 플레이어가 첫 화면에서 두 번 이내의 선택으로 미션을 시작한다.
2. 3분 미션도 완결감 있는 목표와 보상을 제공한다.
3. 같은 미션을 다른 전략으로 다시 시도할 이유가 있다.
4. 실패해도 즉시 게임 오버나 큰 손실 없이 재도전할 수 있다.
5. 학교 쉬는 시간에 안전하게 사용할 수 있고, 외부 채팅·광고·확률형 결제가 없다.

## 2. 핵심 플레이 루프

1. 개척 본부에서 미션을 선택한다.
2. 행성 맵에서 탐험 지역과 경로를 고른다.
3. 제한된 자원과 건설 장비를 준비한다.
4. 탐험 중 자원을 수집하고 선택형 환경 사건을 해결한다.
5. 지역에 건물을 배치하고 목표 시설을 완성한다.
6. 개척·효율·회복 결과를 확인한다.
7. 배지, 신규 지역, 건물, 장비를 해금하고 본부가 성장한다.

플레이어의 핵심 질문은 “정답이 무엇인가?”가 아니라 “지금 가진 자원으로 어떤 전략이 가장 좋은가?”이다.

### 세션 유형

| 세션 | 내용 | 건설 규모 |
|---|---|---:|
| 짧은 미션 | 단일 사건 또는 시설 하나 해결 | 2~3개 |
| 표준 미션 | 한 지역 탐험과 기지 완성 | 4~6개 |
| 장기 미션 | 여러 지역을 연결하고 회복도 상승 | 7~9개 |

플레이 중 언제든 안전하게 저장하고 종료할 수 있다. 미션 종료 후 자동으로 다음 미션을 시작하지 않는다.

## 3. 자원과 건설

### 자원

- **물:** 탐험, 생명체 회복, 생태 온실에 사용한다.
- **에너지:** 발전기, 관측소, 정화 시설을 작동하는 데 사용한다.
- **부품:** 건물 설치와 장비 수리에 사용한다.
- **행성 회복도:** 소비 자원이 아닌 장기 성장 지표다.

자원 수량은 화면 상단에 아이콘과 숫자로 항상 표시한다. 자원 부족 시 자동 절약 모드로 전환해 효율만 낮추며, 기본 미션에서는 즉시 패배시키지 않는다.

### 건물

- 태양광 발전기: 에너지 생산. 폭풍 중 효율이 낮아진다.
- 물 재활용기: 물 생산. 에너지를 소비한다.
- 부품 작업장: 탐험 자원을 건설 부품으로 바꾼다.
- 생태 온실: 물을 사용해 회복도를 올린다.
- 관측소: 주변 지역 정보와 미션을 해금한다.
- 통신 기지: 지역 간 연결과 탐험 범위를 확장한다.

건물은 위치에 따라 효율이 달라진다. 예를 들어 발전기는 열린 평원, 재활용기는 얼음 지대, 온실은 물 재활용기 주변에서 보너스를 얻는다. 배치 보너스는 아이콘과 미리보기로 설명해 시행착오를 줄인다.

## 4. 행성 맵과 탐험

맵은 착륙 기지를 중심으로 연결된 탐험 노드로 구성한다. 초기 지역은 **빛바랜 평원**이며, 이후 **빙하 계곡**, **붉은 협곡**, **빛나는 숲**, **폭풍 고원**을 순차적으로 연다.

- 빛바랜 평원: 기본 자원과 튜토리얼
- 빙하 계곡: 물이 풍부하지만 에너지 소모가 큼
- 붉은 협곡: 부품이 많지만 경로가 복잡함
- 빛나는 숲: 생태 회복과 온실 중심
- 폭풍 고원: 자원 균형을 요구하는 고난도 지역

탐험 사건은 짧은 상황과 2~3개의 선택지로 구성한다. 모든 선택에는 단기·장기 장단점이 있으며 하나의 도덕적 정답만 두지 않는다.

예시:

- 갈라진 에너지 케이블: 에너지로 즉시 수리, 우회, 부품으로 임시 수리
- 이동 중인 외계 생명체: 관찰, 생태 센서 기록, 빠른 통과
- 모래폭풍: 기지로 귀환, 대피소 건설, 위험을 감수한 계속 탐험

재방문 때 경로·자원·사건·건설 위치 일부가 달라지지만, 완전한 무작위가 아닌 검증된 패턴 안에서 변화시켜 공정성을 유지한다.

## 5. 성장과 기록

미션은 다음 세 기준으로 평가한다.

- **개척:** 목표 시설을 완성했는가
- **효율:** 자원을 얼마나 절약했는가
- **회복:** 생태계 회복에 얼마나 기여했는가

각 기준은 별 3개 배지로 표시한다. 한 가지 전략만 정답이 되지 않도록 빠른 성공, 자원 절약, 생태 우선 전략을 모두 보상한다.

플레이 결과에 따라 개척 본부가 텐트에서 발전 시설, 온실, 연구소, 통신 기지를 갖춘 도시로 시각적으로 성장한다. 해금 보상은 고정 목록으로 공개하며, 플레이만으로 획득 가능하다.

지원 로봇은 한 번에 하나를 선택한다.

- 물방울: 탐험 시작 물 +2
- 반짝이: 태양광 발전기 효율 증가
- 똑딱이: 이벤트 선택 시간 증가
- 새싹이: 생태 회복도 획득량 증가

지원 로봇은 능력의 우열보다 플레이 방식의 차이를 만든다. 뽑기나 유료 확률 보상은 사용하지 않는다.

기본 경쟁 지표는 개인 최고 기록이다. 순위표는 기본적으로 비활성화하며, 학교에서 사용하더라도 임의의 개척자 이름과 선택적 참여를 사용한다.

## 6. 화면과 난이도

### 화면 흐름

`개척 본부 → 미션 선택 → 행성 맵 → 탐험·건설 → 결과·보상 → 본부 변화`

미션 화면은 상단 자원, 중앙 플레이 영역, 왼쪽 목표, 오른쪽 건물·장비, 하단 행동 버튼으로 구성한다. 색상만으로 구분하지 않고 아이콘·문자·형태를 함께 사용한다.

### 난이도 단계

1. 착륙 준비: 자원 1~2종, 추천 배치, 즉시 결과 설명
2. 첫 기지: 자원 3종, 건물 3개, 간단한 사건
3. 지역 개척: 경로 선택과 건물 연결 효과
4. 행성 복구: 여러 지역과 날씨 변화 관리
5. 자유 개척: 목표만 제시하고 전략은 자유롭게 선택

기본 미션에는 강제 시간 제한을 두지 않는다. 선택형 도전 미션에서만 시간 제한을 제공한다. 어려운 사건은 필요한 정보를 먼저 보여주며, 실패 결과에는 원인을 한 문장으로 설명한다.

## 7. 안전성과 운영

제외 항목:

- 폭력·공격 중심 전투
- 뽑기·랜덤 상자·확률형 결제
- 광고·외부 링크
- 낯선 사람과의 채팅
- 공개 닉네임과 강제 순위 경쟁
- 연속 출석 보상과 접속을 재촉하는 알림
- 실패 시 큰 자원 손실

교사·보호자 설정은 초기 버전에서 다음으로 제한한다.

- 허용할 최대 플레이 시간
- 허용할 미션 길이
- 공개 순위표 사용 여부
- 임의 개척자 이름 사용 여부
- 저장 데이터 삭제
- 학생 간 기록 공유 여부

개인정보와 학생 이름은 기본적으로 수집하지 않고, 저장은 기기 내 로컬 저장을 우선한다.

## 8. 개념적 구성과 데이터 흐름

주요 구성은 다음과 같다.

- **Mission Catalog:** 지역·목표·사건·보상 정의
- **Planet State:** 자원, 건물, 회복도, 해금 상태
- **Action Resolver:** 탐험·건설·사건 선택의 결과 계산
- **Progression Manager:** 배지, 기록, 해금, 본부 변화 처리
- **Save Manager:** 미션 중간 저장과 결과 저장
- **Policy Settings:** 학교용 시간·경쟁·데이터 설정
- **UI Screens:** 본부, 맵, 미션, 결과 화면

데이터 흐름은 `프로필 로드 → 미션 선택 → 상태 복제 → 행동 검증·결과 계산 → 체크포인트 저장 → 결과 반영 → 진행도 저장` 순서다. 행동이 유효하지 않으면 자원이나 진행도를 변경하지 않고 안내 메시지만 표시한다. 저장 실패 시 현재 세션은 메모리에 유지하고 재시도 버튼을 제공한다.

## 9. 검증 기준

- 동일한 초기 상태와 미션 설정에서 결과가 재현된다.
- 자원은 음수가 되지 않고, 자원 생산·소비 합계가 일치한다.
- 어떤 지역도 한 가지 건물 조합만으로 항상 최적화되지 않는다.
- 미션을 중간 종료해도 저장 데이터가 손상되지 않는다.
- 각 미션은 3·5·10·15분 목표 중 하나로 명확히 표시된다.
- 실패 시 부분 보상이 지급되고 재도전 경로가 안내된다.
- 광고, 외부 링크, 채팅, 확률형 보상이 노출되지 않는다.
- 모든 핵심 버튼과 자원 상태를 아이콘과 텍스트로 확인할 수 있다.

## 10. 초기 버전 범위

초기 버전은 다음만 포함한다.

- 평원·빙하 계곡·빛나는 숲 3개 지역
- 자원 3종
- 건물 6종
- 탐험 사건 12개
- 지원 로봇 4종
- 미션 15개
- 개인 기록과 로컬 저장
- 교사·보호자용 기본 플레이 시간 설정

온라인 순위표, 계정 시스템, 학생 간 공유, 추가 콘텐츠 제작 도구는 초기 버전 이후로 미룬다.
